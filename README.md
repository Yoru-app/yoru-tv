# Yoru TV — Android TV-версия Yoru

Нативное приложение для Android TV и Google TV на Kotlin и Jetpack Compose: тот же Yoru, но под пульт.
Названия и постеры берутся с Shikimori, видео и переводы — с Anime365, горизонтальные баннеры — с AniList (запасной источник — Kitsu).

## Что есть

| Ряды на главной | «Продолжить просмотр» и «Новые серии из списка» — широкими карточками с баннером, дальше «Смотрю», «Свежие переводы Anime365», «Сегодня выходит», «Сейчас выходит», «Аниме сезона», «Запланировано», «Лучшее» |
| Каталог и поиск | Один раздел: поиск (клавиатура ТВ, голосовой ввод), сортировка, статус, тип, год, жанры, бесконечная сетка |
| Страница тайтла | Баннер, факты, «Сезон N из M» на постере, логотип названия с TMDB над заголовком, «Продолжить: серия N», «Мой список» (статус, серии, оценка → Shikimori), избранное, серии с разбивкой по 50 (без трейлеров и PV), «Хронология», «Связанное», «Похожее», «Персонажи», «Кадры» (OK — на весь экран) |

| Настройки по разделам | Аккаунт, Главный экран, Аниме, Плеер, Android TV, Данные |

## Превью при перемотке

Один кадр на 15 секунд шкалы, из самого лёгкого MP4 серии. Кадры подгружаются только во время перемотки: сначала нужный, затем несколько впереди. Включается в «Настройки → Плеер» и в настройках самого плеера.

## Быстродействие

- **Профиль базовой компиляции** (`app/src/main/baseline-prof.txt`): код приложения Android компилирует заранее, поэтому первые показы экранов не тормозят.
- **Главная из кэша:** при запуске сразу показывается прошлая главная, ряды обновляются по мере ответа источников. Один медленный источник не держит экран.
- **Запуск не ждёт диск:** список Shikimori, кэши баннеров и TMDB читаются в фоне; большие значения хранятся в `files/kv`, а не в SharedPreferences.
- **Плеер:** позиция больше не перерисовывает весь экран 5 раз в секунду; воспроизведение начинается при секунде буфера; замер CDN не повторяется 30 минут.
- **«Для слабых ТВ»** («Настройки → Главный экран»): без большого блока на главной, фона на странице тайтла, анимаций и размытия, меньше памяти под картинки и видео. Превью при перемотке выключается, его можно вернуть.

## Логотип

Маскот из веб-Yoru 2.7 (`public/logo.svg`): векторный `res/drawable/yoru_logo.xml` в меню и на экране подключения,
он же на иконке приложения, баннере лаунчера и логотипе каналов (PNG в `mipmap-*`, `drawable-xhdpi/banner.png`, `drawable-nodpi/channel_logo.png`).

## Пульт

**Везде:** стрелки — фокус, OK — выбрать, «Назад» — назад. На главной «Назад» сначала поднимает к началу страницы. Влево от контента открывается боковое меню.

**Плеер, панель скрыта:**

| Кнопка | Действие |
|---|---|
| OK | пауза/пуск и показать панель (когда видна плашка «Пропустить заставку» — пропустить, +85 с) |
| ← / → | −10 / +10 с; если держать — шаг растёт до 30 и 60 с |
| ↑ | панель с фокусом на полосе перемотки (там ←/→ тоже перематывают) |
| ↓ | панель с фокусом на кнопке паузы |
| ⏯ ⏪ ⏩ | пауза, −30 с, +30 с |
| ⏭ ⏮, CH+ / CH− | следующая / предыдущая серия |
| CC | субтитры вкл/выкл |
| 0–9 | перейти к 0 %…90 % серии |
| Меню | настройки плеера |

## Сборка

1. Установите [Android Studio](https://developer.android.com/studio) и откройте папку `yoru-tv`. Студия сама скачает Gradle, SDK и зависимости.
2. *(Необязательно)* скопируйте `local.properties.example` в `local.properties` и впишите `shiki.clientId`, `shiki.clientSecret`, `shiki.appName`. Если этого не сделать, данные приложения Shikimori можно ввести позже со страницы подключения на телефоне.
3. Run ▶ на эмуляторе или телевизоре (см. ниже), либо `Build → Build APK(s)`.

> Проект не собирался в среде, где он написан: там не было доступа к Google Maven. Если при первой сборке Android Studio покажет ошибки компиляции, пришлите текст ошибок — исправлю.

### Приложение Shikimori

Нужно одно приложение на [shikimori.io/oauth/applications](https://shikimori.io/oauth/applications) с правом `user_rates`.
В поле Redirect URI должна быть строка `urn:ietf:wg:oauth:2.0:oob`: на телевизоре нет адресной строки, поэтому Shikimori показывает код, а приложение его обменивает.
Можно добавить эту строку в уже существующее приложение веб-Yoru или завести отдельное. Название приложения уходит в User-Agent каждого запроса, как требует Shikimori.

### Первый запуск: подключение с телефона

На первом запуске (и в «Настройки → Аккаунты») открывается экран подключения с QR-кодом. Телефон в той же Wi‑Fi сети открывает страницу, которую отдаёт сам телевизор (порт 8365). Там можно:

- ввести `client_id` / `client_secret` приложения Shikimori, если они не прописаны при сборке;
- нажать «Войти через Shikimori», скопировать код и вставить его в поле;
- открыть страницу токена Anime365 и вставить токен (тот же, что в веб-Yoru; нужна подписка).

Пультом всё это тоже можно ввести, но с телефона заметно быстрее. Сервер на телевизоре работает только пока открыт этот экран, а ссылка содержит одноразовый ключ.

## Баннеры, обложки и логотипы

«Настройки → Аниме → Баннеры и обложки»:

- **Баннеры:** AniList (запасные — Kitsu и кадр с Shikimori) или TMDB, как на AniScroll. Если в TMDB чего-то нет, картинка берётся из AniList.
- **Обложки:** Shikimori или AniList.
- **Логотип названия в плеере** (по центру, когда видна панель) берётся из TMDB. Без ключа там показывается название текстом.

Для TMDB нужен бесплатный ключ: themoviedb.org → Настройки → API. Подойдёт и «API Read Access Token», и короткий API Key. Ключ вводится на странице подключения с телефона или прописывается в `local.properties` как `tmdb.token`. Соответствие MyAnimeList → TMDB берётся из открытых таблиц arm.haglund.dev и animeapi.my.id. Если `api.themoviedb.org` у вашего провайдера заблокирован, оставьте баннеры AniList.

## Каналы на главном экране

«Настройки → Android TV» — та же подборка, что у хиро-блока. Каждая отмеченная подборка становится отдельным каналом; карточки — баннеры 16:9 (AniList → Kitsu → кадр с Shikimori → постер). Первый канал Android TV показывает сам, для остальных телевизор спросит разрешение (кнопка «Показать» в настройках). Обновление — раз в 3 часа через WorkManager и при каждом запуске.

**Важно:** на классическом лаунчере Android TV каналы работают. Лаунчер Google TV (Chromecast с Google TV, многие телевизоры 2021+) сторонние каналы часто не показывает — это ограничение лаунчера, не приложения. Ряд «Продолжить просмотр» (Watch Next) там обычно работает.

## Как тестировать на Windows, не переустанавливая APK на телевизор

1. **Эмулятор Android TV в Android Studio.** Device Manager → Create Device → категория *TV* → «Television (1080p)» → образ *Android TV* (для каналов берите именно Android TV, не Google TV; API 31–34). Стрелки и Enter на клавиатуре работают как пульт; «Назад», «Домой» и крестовина пульта есть в боковой панели эмулятора (⋯ → Extended controls → Directional pad).
2. **Apply Changes и Live Edit.** После первого запуска правки в коде применяются без переустановки: `Apply Changes` (Ctrl+Alt+F10 / Ctrl+F10), а для Compose — Live Edit (Settings → Editor → Live Edit), изменения UI видны сразу на эмуляторе.
3. **Compose Preview.** Для экранов можно добавить `@Preview(device = "spec:width=1920px,height=1080px,dpi=320")` — это размер 1080p-телевизора, и смотреть вёрстку прямо в студии, в том числе в интерактивном режиме.
4. **Отладка на настоящем телевизоре по Wi‑Fi.** На ТВ: Настройки → Об устройстве → 7 раз нажать на «Сборка» → в «Для разработчиков» включить отладку по сети (или по USB + `adb tcpip 5555`). На ПК: `adb connect IP_ТЕЛЕВИЗОРА:5555`, после этого телевизор появляется в списке устройств Android Studio — кнопка Run ставит и обновляет приложение сама, Apply Changes работает так же, как с эмулятором.
5. **scrcpy** ([github.com/Genymobile/scrcpy](https://github.com/Genymobile/scrcpy), есть сборка для Windows) — показывает экран телевизора в окне на ПК и передаёт клавиатуру как пульт. Работает поверх того же `adb connect`, удобно для скриншотов и долгих сессий.
6. **Страница подключения в эмуляторе.** Эмулятор живёт в своей сети, поэтому QR не откроется с телефона. Выполните `adb forward tcp:8365 tcp:8365` и откройте на ПК `http://localhost:8365/?k=КЛЮЧ` (ключ — в конце адреса под QR-кодом).
7. **Ссылки из каналов** можно проверить без лаунчера:
   ```
   adb shell am start -a android.intent.action.VIEW -d "yoru://title/52991"
   adb shell am start -a android.intent.action.VIEW -d "yoru://watch/52991?n=3"
   ```
8. **Готовый APK без локальной сборки.** В `.github/workflows/apk.yml` есть сборка на GitHub Actions: запушьте проект в свой репозиторий, и APK появится во вкладке Actions → артефакт `yoru-tv-debug`.

## Отличия от веб-версии

- Телевизор ходит в Anime365 и Shikimori напрямую, а не через сервер Yoru: токен Anime365 и вход Shikimori хранятся на самом телевизоре. Режимы видео «через сервер», дневные лимиты и права администратора из веб-Yoru здесь не действуют — это личное устройство.
- Канал CDN на сайте Anime365 через API не переключить; плеер, как и веб, замеряет скорость каждого адреса из `stream[].urls`, начинает с самого быстрого и переключается при ошибке. Последний запасной вариант — MP4 с сайта.
- Встраивать плеер сайта через WebView не стали: там та же проблема со входом, что и у iframe.
